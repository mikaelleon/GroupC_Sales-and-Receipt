## Before presentation (rubric focus)

The rubric weights **Database Integration**, **CRUD Operations**, and **System Functionality** heavily. In the live demo, clearly show:

1. **CRUD** — add/update/deactivate product; add/update category; register cashier  
2. **Database** — dashboard KPIs refresh; sale saves; stock deducts; audit log entry  
3. **All 10 features** — use [05-features-checklist.md](05-features-checklist.md) as a tick list during rehearsal
