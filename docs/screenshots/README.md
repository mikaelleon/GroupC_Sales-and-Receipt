## Capture tips

1. Run app **maximized** at 1920×1080 if possible  
2. Use **Admin login** for admin screens; create sample data first  
3. Hide unrelated windows (browser, IDE)  
4. Windows: **Win + Shift + S** → save into this folder  
5. In Word/PDF, caption each figure: *“Figure N. [Screen name] — [one sentence description]”*
